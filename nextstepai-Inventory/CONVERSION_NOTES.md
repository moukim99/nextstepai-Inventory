# Conversion Notes

- [Login Screen / SSO Login]: Responsive `BoxWithConstraints` switching dynamically between mobile handheld card layout (≤ 840dp) and desktop enterprise dual-pane split shell layout (> 840dp) — Reason: Replaced CSS container queries with native Compose responsive layout to support both handheld Android terminals and wide Desktop windows seamlessly from a unified KMP codebase.
- [Login Screen / SSO Login]: Replaced CSS keyframe ping animation with Compose `rememberInfiniteTransition` pulsing scale and alpha effect — Reason: Native Compose animation for live cloud connection telemetry indicator.
- [Login Screen / SSO Login]: Integrated unified Material 3 `ColorScheme` with design system tokens in `AppTheme.kt` — Reason: Ensures consistent design tokens (`primaryContainer`, `surfaceVariant`, `tertiaryContainer`, `inverseSurface`) without hardcoding raw hex values in UI composables.
- [Main Dashboard Screen]: Aligned welcome banner icon badge layout, placed dark Barcode/QR quick scanner card immediately after KPIs section, and refined domain cards styling to match target HTML design — Reason: Delivers 100% visual parity with target design.
- [Main Dashboard Screen]: Updated string resources to provide clean Arabic navigation bar labels — Reason: Prevents English fallback labels in navigation suite scaffold.
- [Build Orders Screen / Build]: Converted HTML UI into native Jetpack Compose `BuildOrderRichCard`, `AddBuildSheetDialog`, and `BuildStatus` filter chips tray — Reason: Aligns with InvenTree build order workflow while preserving ViewModel state and repository logic.
- [Global App Insets & Top Bar Standardization]: Added `statusBarsPadding()` across `App.kt`, `PurchaseOrderScreen`, `CompanyScreen`, `StockScreen`, `PartManagementScreen`, and `BomScreen` — Reason: Prevents top app bar overlap with Android system status bar (clock, wifi, battery icons).
- [Global Screen Layout Standard]: Applied unified RTL top bar layout (Back button + Title on RIGHT, Action button on LEFT), integrated Search & QR Barcode trigger inputs, and status filter chip trays across all 7 app screens — Reason: Establishes a cohesive, enterprise-grade UX/UI standard across the entire application.
